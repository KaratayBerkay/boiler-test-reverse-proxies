# Headers, limits and security - construct per proxy

Probe ids: `xff_headers`, `forwarded_rfc7239`, `request_id`, `custom_headers`, `hide_server_headers`, `rate_limit`,
`connection_limit`, `ip_allow`, `ip_deny`, `basic_auth`, `jwt_auth`, `forward_auth`, `body_limit`, `timeout_upstream`,
`fault_injection`, `bandwidth_limit`, `static_files`, `custom_error_page`, `cors`, `security_headers`.

## Forwarded headers and request ids
- **X-Forwarded-For/Proto/Host, X-Real-IP** - automatic in HAProxy (`option forwardfor`), Caddy, Traefik, Envoy (`use_remote_address: true`), Apache (`ProxyAddHeaders On`), Kong, APISIX, ATS (`insert_squid_x_forwarded_for`). nginx/OpenResty/Varnish/Pingora set them explicitly (`proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for; X-Forwarded-Proto $scheme; X-Real-IP $remote_addr`). Trust boundaries: nginx `set_real_ip_from` + `real_ip_header`; Caddy `trusted_proxies static <cidr>`; Traefik `forwardedHeaders.trustedIPs`; Envoy `xff_num_trusted_hops`; Kong `KONG_TRUSTED_IPS`; APISIX `real-ip` plugin `trusted_addresses`.
- **RFC 7239 `Forwarded`** - HAProxy `option forwarded proto host for` (2.8+); everyone else builds it by hand (`for=<ip>;proto=<scheme>;host=<host>`); Traefik **cannot** (unsupported).
- **X-Request-ID** - nginx `map $http_x_request_id $req_id { default $http_x_request_id; "" $request_id; }`; HAProxy `unique-id-format` + `set-header X-Request-ID %[unique-id] unless { req.hdr(X-Request-ID) -m found }`; Caddy `{http.request.uuid}`; Envoy `generate_request_id` + `preserve_external_request_id`; Apache mod_unique_id `RequestHeader setifempty X-Request-ID "%{UNIQUE_ID}e"`; Varnish `uuid.uuid_v4()`; Kong `correlation-id` plugin; APISIX `request-id` plugin; Pingora `uuid`; ATS `%{ID:UNIQUE}` in header_rewrite; Traefik **unsupported** (plugin).
- **Hide upstream `X-Powered-By` / server tokens** - nginx `proxy_hide_header X-Powered-By; server_tokens off`; HAProxy `http-response del-header X-Powered-By`; Caddy `header_down -X-Powered-By -Server`; Traefik `customResponseHeaders: { X-Powered-By: "" }`; Envoy `response_headers_to_remove`; Apache `Header always unset X-Powered-By` **and** `Header unset` (two tables), `ServerTokens Prod`; Varnish `unset resp.http.X-Powered-By` + `unset resp.http.Via`; Kong `response-transformer remove`; APISIX `response-rewrite headers.remove`; Pingora `resp.remove_header`; ATS `rm-header` in `READ_RESPONSE_HDR_HOOK`, `response_server_str`.

## Rate and connection limits (per client IP: 10 r/s burst 5; 3 concurrent)
- nginx / OpenResty: `limit_req_zone $binary_remote_addr zone=r:10m rate=10r/s; limit_req zone=r burst=5 nodelay; limit_req_status 429;` / `limit_conn_zone ...; limit_conn c 3;` (OpenResty alternative: `resty.limit.req` / `resty.limit.conn` in `access_by_lua`).
- HAProxy: stick tables `stick-table type ip size 100k expire 30s store http_req_rate(1s)` + `track-sc0 src` + `deny deny_status 429 if { sc_http_req_rate(0) gt 10 }`; `store conn_cur` + `sc_conn_cur(1) gt 3`.
- Caddy: `rate_limit { zone z { key {client_ip}  events 10  window 1s } }` (caddy-ratelimit plugin, `order rate_limit before basic_auth`); concurrency **unsupported**.
- Traefik: `rateLimit: { average: 10, period: 1s, burst: 5, sourceCriterion: { ipStrategy: { depth: 0 } } }`; `inFlightReq: { amount: 3 }`.
- Envoy: `local_ratelimit` per route `token_bucket: { max_tokens: 15, tokens_per_fill: 10, fill_interval: 1s }` (per route, not per client - per-client needs descriptors / the global ratelimit service); concurrency per client **unsupported** (connection_limit is per listener).
- Apache: **unsupported** in core (mod_qos / mod_evasive third-party; mod_ratelimit is bandwidth).
- Varnish: `vsthrottle.is_denied("" + client.ip, 10, 1s, 10s)`; concurrency **unsupported**.
- Kong: `rate-limiting { second: 10, policy: local, limit_by: ip, error_code: 429 }`; concurrency **unsupported** in OSS.
- APISIX: `limit-req { rate: 10, burst: 5, key: remote_addr, nodelay: true, rejected_code: 429 }`; `limit-conn { conn: 3, burst: 0, key: remote_addr }`.
- Pingora: `pingora_limits::rate::Rate` (`observe(&ip, 1) > 10`) and `Inflight` guards.
- ATS: `rate_limit.so --limit=3 --queue=0 --error=429` = **concurrency per remap**, no per-client rps limit.

## IP allow / deny
- nginx: `allow 10.77.0.1; deny all;` / `deny 10.77.0.0/24; allow all;` · HAProxy: `http-request deny if !{ src 10.77.0.1 }` / `if { src 10.77.0.0/24 }` · Caddy: `@m { path /allowed  not client_ip 10.77.0.1/32 }  handle @m { respond 403 }` · Traefik: `ipAllowList: { sourceRange: [...] }` (deny = allow-list of another range) · Envoy: `RBACPerRoute` with `direct_remote_ip` principals, `action: ALLOW|DENY` · Apache: `Require ip 10.77.0.1` / `<RequireAll> Require all granted; Require not ip 10.77.0.0/24` · Varnish: `acl` + `client.ip ~ acl` · Kong: `ip-restriction { allow | deny, status: 403 }` · APISIX: `ip-restriction { whitelist | blacklist }` · Pingora: string compare on `client_ip` · ATS: `header_rewrite` `cond %{IP:CLIENT} ...` + `set-status 403` (or `ip_allow.yaml` globally).

## Authentication
- **Basic**: nginx `auth_basic` + `auth_basic_user_file` (htpasswd apr1/bcrypt) · HAProxy `userlist` + `http-request auth realm x if !{ http_auth(list) }` · Caddy `basic_auth { user <bcrypt> }` · Traefik `basicAuth: { users: [...] }` · Envoy `basic_auth` filter (`users: htpasswd` **SHA-1 `{SHA}` only**), scoped with `ExtensionWithMatcher` · Apache `AuthType Basic; AuthUserFile; Require valid-user` · Varnish compare with `digest.base64("user:pass")` · Kong `basic-auth` + consumer credentials · APISIX `basic-auth` + consumer · Pingora base64 compare · ATS header_rewrite compare of the literal header.
- **JWT (HS256, exp checked)**: nginx OSS via **njs** (`auth_request` -> `js_content` HMAC check; `auth_jwt` is Plus) · HAProxy `jwt_verify("HS256","secret")` + `jwt_payload_query('$.exp','int'),sub(txn.now) -m int lt 1` · Caddy `jwtauth { sign_key <base64>  sign_alg HS256  from_header Authorization  user_claims sub }` (caddy-jwt) · Traefik **unsupported** (plugin/Enterprise) · Envoy `jwt_authn` with `local_jwks` (oct key) + `requirement_map` + per-vhost `PerRouteConfig` · Apache **unsupported** (mod_auth_openidc third-party) · Varnish pure VCL with `digest.hmac_sha256` + `base64url_nopad_hex` · OpenResty `resty.jwt:verify(secret, token, { exp = validators.is_not_expired() })` · Kong `jwt { key_claim_name: iss, claims_to_verify: [exp] }` + consumer `jwt_secrets` · APISIX `jwt-auth { key_claim_name: iss }` + consumer · Pingora `jsonwebtoken` · ATS **unsupported**.
- **Forward auth (ask `GET /auth` first, copy `X-Auth-User`)**: nginx `auth_request /_auth` + `auth_request_set $u $upstream_http_x_auth_user` · HAProxy Lua action with `core.httpclient()` (needs `httpclient.resolvers.id`) · Caddy `forward_auth app1:8080 { uri /auth  copy_headers X-Auth-User }` · Traefik `forwardAuth: { address, authResponseHeaders }` · Envoy `ext_authz` `http_service` (`path_prefix`, `allowed_headers`, `allowed_upstream_headers`) scoped by matcher · Apache **unsupported** · Varnish `vmod_reqwest` client in `vcl_recv` · OpenResty `ngx.location.capture("/_auth")` · Kong **unsupported** in OSS · APISIX `forward-auth { uri, request_headers, upstream_headers, client_headers }` · Pingora **not written** · ATS **unsupported** (authproxy.so forwards the original path).

## Body limit, fault injection, bandwidth
- **413 on > 1 MiB**: nginx `client_max_body_size 1m` · HAProxy `deny deny_status 413 if { req.hdr_val(content-length) gt 1048576 }` · Caddy `request_body { max_size 1MB }` · Traefik `buffering: { maxRequestBodyBytes }` · Envoy `BufferPerRoute { max_request_bytes }` · Apache `LimitRequestBody` **plus** a `RewriteCond %{HTTP:Content-Length} >1048576` (not enforced on streamed proxy bodies) · Varnish `std.integer(req.http.Content-Length, 0) > 1048576` · Kong `request-size-limiting { allowed_payload_size: 1, size_unit: megabytes }` · APISIX `client-control { max_body_size }` · Pingora Content-Length check · ATS header_rewrite on `Content-Length`.
- **Fault injection (20 % 503)**: nginx `split_clients "${request_id}" $f { 20% "1"; * ""; }` + `if ($f) { return 503; }` · HAProxy `deny deny_status 503 if { rand(100) lt 20 }` · Caddy **unsupported** · Traefik **unsupported** · Envoy `fault` filter `abort: { http_status: 503, percentage: { numerator: 20 } }` · Apache `RewriteMap rnd:` lottery file inside the vhost/macro · Varnish `std.random(0, 100) < 20` · OpenResty `math.random() < 0.2` · Kong `pre-function` Lua · APISIX `fault-injection { abort: { http_status: 503, percentage: 20 } }` · Pingora `rand::random::<f64>() < 0.2` · ATS `cond %{RANDOM:100} <20`.
- **Bandwidth 500 KB/s**: nginx `limit_rate 500k` · HAProxy `filter bwlim-out lab_bw default-limit 500000 default-period 1s` + `http-response set-bandwidth-limit lab_bw` · Caddy/Traefik **unsupported** · Envoy `bandwidth_limit { enable_mode: RESPONSE, limit_kbps: 488, fill_interval: 0.05s }` (1 s burst) · Apache `SetOutputFilter RATE_LIMIT` + `SetEnv rate-limit 500` · Varnish/Kong/Pingora **unsupported** · APISIX `serverless-pre-function` setting `ngx.var.limit_rate = 500000` · ATS **unsupported** in containers (`fq_pacing.so` needs the fq qdisc).

## Static files, custom error pages, CORS, security headers
- **Static file served by the proxy**: nginx `location /static/ { alias /static/; }` · HAProxy `http-request return status 200 content-type text/html file /static/index.html` · Caddy `handle_path /static/* { root * /static  file_server }` · Traefik **unsupported** · Envoy `direct_response: { status: 200, body: { filename } }` · Apache `Alias` + `ProxyPass /static/ !` · Varnish `fileserver.root("/static")` backend · Kong `pre-function` reading the file (`KONG_UNTRUSTED_LUA=on`) · APISIX `serverless-pre-function` · Pingora body from a `LazyLock<String>` · ATS `statichit.so --file-path=... --disable-exact` with an empty remapped path.
- **Replace an upstream 5xx with a custom page**: nginx `proxy_intercept_errors on; error_page 503 /_error.html;` (internal location, `add_header X-Error-Page custom always`) · HAProxy `http-response return status 503 ... file /static/error.html hdr X-Error-Page custom if { status 503 }` · Caddy `handle_response @err { root * /static  rewrite * /error.html  file_server { status 503 } }` · Traefik `errors: { status: ["500-599"], service: static, query: /error.html }` · Envoy per-route Lua `envoy_on_response` rewriting the body (`h:body(true):setBytes`) · Apache `ProxyErrorOverride On` + `ErrorDocument 503 /error.html` · Varnish `return (error(status))` -> `vcl_backend_error` `synthetic(std.fileread(...))` · Kong `post-function` with `enable_buffering()` + `body_filter` `set_raw_body` · APISIX `response-rewrite { vars: [["status","==",503]], body }` · Pingora `response_body_filter` · ATS **unsupported** (origin bodies pass through; body_factory only styles ATS's own errors).
- **CORS preflight**: nginx `if ($request_method = OPTIONS) { add_header ... always; return 204; }` · HAProxy `http-request return status 204 hdr Access-Control-Allow-Origin %[req.hdr(origin)] ... METH_OPTIONS` · Caddy matcher + `header` + `respond 204` · Traefik `headers: { accessControlAllowOriginList, accessControlAllowMethods, ... }` · Envoy `cors` filter + per-route `CorsPolicy` · Apache mod_headers + RewriteRule 204 · Varnish `synth(752)` · Kong `cors` plugin · APISIX `cors` plugin · Pingora `reply(204, headers)` · ATS header_rewrite `set-status 204` + response headers.
- **HSTS / nosniff / frame / referrer**: `add_header ... always` (nginx: `always` or 4xx/5xx lose them) · HAProxy `http-response set-header` · Caddy `header` · Traefik `headers: { stsSeconds, forceSTSHeader: true, contentTypeNosniff, frameDeny, referrerPolicy }` · Envoy `response_headers_to_add` · Apache `Header always set` · Varnish `set resp.http.*` in `vcl_deliver` · Kong `response-transformer add` · APISIX `response-rewrite headers.set` · Pingora `resp.insert_header` · ATS `SEND_RESPONSE_HDR_HOOK set-header`.
